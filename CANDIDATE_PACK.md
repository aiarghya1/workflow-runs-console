# Candidate Pack

Read `CHALLENGE.md` first.

This workspace is intentionally lightweight. It gives you:
- the challenge prompt
- sample workflow run data
- a starter folder structure
- baseline contracts for the domain

## Working Rules

- You may use Cursor and internet search.
- Keep the solution thin and working.
- Prefer a complete core flow over broad unfinished work.
- Explain your thinking as you work.

## Timebox

You will get:
- a short discussion before coding
- `60 minutes` of build time
- a short discussion after the build

## Suggested Workspace Areas

- `frontend/` for UI work
- `backend/` for API or service work
- `shared/contracts/` for shared models or request/response shapes
- `fixtures/` for sample data and local mocks

Use the stack defined by the interviewer. If a stack is not specified, choose one you can deliver in quickly.
